# Gemini's suggestion inbox

The ONE file Gemini may write to, per the working agreement in `GEMINI.md` at the repo root.
Append below the line: dated, in prose, saying what, why, and which files it would touch.
Nothing here is a decision. Claude verifies each entry against the sources of truth; the
owner rules on anything that survives.

Format:

```
## 2026-08-17 — 412 Maple St frontage
The real house is a brick foursquare with a full-width porch (Street View, heading 40);
the generated one is clapboard. Suggest: frontage change in kinds/particulars, or flag
for an owner model. Files: Content/particulars.txt (or Content/models.txt if modeled).
```

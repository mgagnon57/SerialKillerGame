# Each line is a clause. The renderer prefixes a name: "Ivy Pethick whistles badly, and

# These exist to fail the test of usefulness. Nothing here helps anyone do anything. That is

# When we measure whether watching someone yields more useless information than useful, THIS
# is the numerator.
#
# Rules for adding more:
#   - specific, not characterful. "keeps a jar of buttons" beats "is eccentric".
#   - ordinary. No secrets, no tragedies, no foreshadowing.
#   - observable, or nearly so. Someone watching for a week could plausibly learn it.
#   - 1979, rural England. The wireless, the immersion, the pools, four-star, the fish van.
#   - never a demographic label and never an assessment. A particular is the texture of a
#     life, not a judgement on one.
#   - never a checklist of who is unprotected. No keys, no unlocked doors, no empty houses,
#     no "nobody ever calls". There is exactly one lock clause in this file and it is enough.
#   - PRONOUN-FREE, and sex-free. The renderer prefixes a name without consulting who owns it,
#     so "cuts his own hair" becomes "Ruth Hocking cuts his own hair, badly". Write the clause
#     so it fits anybody. Check every line you add.

# The table has a silent population ceiling and crossing it throws nothing. Expected number of
# people sharing any one clause is  N x 2.4 / C  where N is the town and C is the clause count.

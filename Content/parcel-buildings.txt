# ============================================================================
#  THE BUILDINGS OF ROSSVILLE, AS SOMETHING ACTUALLY MEASURED THEM
#
#  822 building footprints, seated on the county's own lots. Until this file, no
#  building in this project stood anywhere a survey put it: houses are authored
#  rectangles placed at a setback from a road, and 76 of them stand on no parcel at
#  all. These are polygons, from imagery, with an area and an address each.
#
#  SOURCE. FEMA / Oak Ridge National Laboratory USA Structures, the national
#  building-footprint layer, queried for the Rossville box on 2026-08-05. Raw download
#  at tools/rossville-structures.geojson so this can be rebuilt; the seating is
#  tools/seat-buildings.py and the coordinate fit it depends on is tools/fit-transform.py.
#
#  885 structures stand in the box. 822 are seated here; 57 fall on no county parcel
#  (open country, where the parcels tile farmland) and 6 on a lot parcels.txt does not
#  carry. For scale, OpenStreetMap has 19 buildings here and Vermilion County's own
#  Buildings layer has none - that layer exists and covers Danville only, which is why
#  earlier passes recorded the county as having no footprint data. It has none HERE.
#
#  HOW GOOD IS THE SEATING. Two independent checks, both computed rather than asserted:
#
#    822 of 822 footprints land inside the very lot they were assigned to, in the
#    coordinates parcels.txt draws - so a house sits on its own lot, not the
#    neighbour's. 69% sit wholly inside their boundary; the rest overhang it, which is
#    partly real - garages are built on lot lines - and partly the tracing being loose.
#
#    96.0% of them carry the same street address the county assessor records for the
#    same parcel (679 agree, 28 differ, on the 707 where both sides have one). The two
#    datasets are unrelated - a county tax roll and a federal imagery product - so
#    agreeing on which house is at which number is a real check on the geometry.
#    Most disagreements are two house numbers apart on the right street.
#
#  WHAT IS NOT IN HERE, AND DO NOT INFER IT.
#    - NO HEIGHTS. The HEIGHT column is empty on all 808 records.
#    - NO ROOM DATA. Nothing here says bedrooms, baths or floor area; footprint is
#      GROUND AREA, and a 1.5-storey house has half again as much floor as this says.
#    - NO YEAR BUILT. See docs/research/ROSSVILLE-HISTORY.md for the era mix.
#    - EVERY RECORD IS `VAL_METHOD: Automated`. Not one was checked by a person. These
#      are machine-traced outlines: right about where a building is, approximate about
#      its exact corners, and they include porches, attached garages and later
#      additions that the 1913 Sanborn footprints deliberately exclude.
#    - THE PRIMARY/OUTBUILDING SPLIT IS DERIVED, NOT RECORDED. FEMA ships an OUTBLDG
#      flag and it is empty on every record, so the largest structure on a lot is
#      called the building and the rest are behind it.
#
#  These are CURRENT buildings, imagery-dated 2016 on most records, and the game is set
#  around 2000. The commercial row at Attica x Chicago burned in February 2004, so the
#  downtown here is the town AFTER the fire and is wrong for the build year - see
#  docs/research/DOWNTOWN-1991.md. The residential streets are substantially unchanged.
#
#  FIELDS
#    parcel <id> building <n> <role> <area> <zone> "<address>"
#        n       0 is the largest structure on the lot, then descending
#        role    primary | outbuilding, derived as above
#        area    footprint ground area in SQUARE METRES, to match parcels.txt and
#                ResidentialLots.Homestead.Footprint. The header talks in square feet
#                because the town does; the file is metric because the code is.
#        zone    FEMA's occupancy class, mapped onto the project's own zoning words
#        skew    degrees this outline sits off square to its own lot, signed. RECORDED,
#                NOT CORRECTED - rotate the ring by minus this about its own centroid to
#                square it. See the note on tracing quality above before doing so.
#    parcel <id> shape <n> x,y x,y ...
#        the footprint ring, closed, in village metres - the same frame as parcels.txt
#
#  Keyed by parcel id, which is that parcel's line number in parcels.txt (0-based,
#  comments and blanks not counted), matching parcel-county.txt and parcel-notes.txt.
#
#  DERIVED AND READ-ONLY, like parcel-county.txt. Nothing authored belongs in here -
#  parcel-notes.txt is the author's file and the game rewrites it whole.
# ============================================================================

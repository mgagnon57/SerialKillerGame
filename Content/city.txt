# ============================================================================
#  NORTHGATE
#
#  360 x 360 tiles, one tile = one metre. The city fills the north-west quadrant
#  exactly as it did; the other three are country.
#
#      0                       240                 360
#  0   +--------------------------+-------------------+
#      |                          |                   |
#      |     T H E   C I T Y      |   the east fields |
#      |     nine 60m blocks      |   and the orchard |
#      |     four junctions       |                   |
#  240 +--------------------------+-------------------+
#      |  HOME FARM               |  the back place   |
#      |  and the cornfields      |  no made road     |
#  360 +--------------------------+-------------------+
#
#  THE ROAD KIT DECIDES THE GRID, not taste. Prefabs/City/Roads City is built at
#  thirty metres, so a through-road is a THIRTY-METRE CORRIDOR and the plan snaps
#  to thirty. What differs between an arterial and a main road is not the corridor
#  - both are thirty - but how much of it is asphalt:
#
#    freeway    30m corridor, 24m asphalt, two lanes each way, orange centre
#    mainroad   30m corridor, 12m asphalt, one lane each way
#    street     10m corridor,  6m asphalt, unmarked
#    track      10m corridor,  7m of dirt, no kerb and no markings
#
#  Because width alone cannot tell a freeway from a mainroad, the class is said
#  outright on an indented `class` line rather than inferred.
#
#  A ROAD IS TILED BETWEEN THE POINTS IT IS DECLARED BETWEEN. The four city roads
#  are declared edge to edge and so cross the whole map; a farm track is declared
#  from a map edge to the road it joins, and stops there. Declaring a track that
#  stops in a field would leave traffic driving off the end of it.
#
#  THE GROUND: grass everywhere, then the city paved over the top of it. Trees,
#  hedges and bushes are scattered by Prop.ScatterOn, which fires on grass, field,
#  wood and churchyard and on NOTHING else - so paving the city is what stops a
#  hedge growing down the middle of the avenue, and leaving the country unpaved is
#  what lets it grow anywhere at all.
#
#  Painted in order: terrain, then roads over terrain, then places over roads. An
#  open place STAMPS ITS GROUND, so a place laid over a road must have road for
#  its ground or it quietly erases the street - which is what the Elevated did to
#  Second Street in an earlier plan.
# ============================================================================

# ==========================================================================
#  DOWNTOWN
#
#  THE TOWN IS THE INNER RING, not nine blocks in the middle of it. Northgate
#  used to be a 3x3 grid of sixty-metre blocks sitting alone inside five hundred
#  metres of arterial road, which reads as a village with a motorway network
#  bolted round it. The streets at 345, 615 and 705 close the grid up: with the
#  four that were already there, the square between the ring roads is now SIX
#  block-bands each way - thirty-six blocks of sixty metres, which is the scale
#  of a small city's walkable core rather than a hamlet's.
#
#  Nine of those blocks are the town as it was and are authored building by
#  building above. The other twenty-seven are `district`: an open place that
#  CityDistrict fills with a block - a perimeter of stacked buildings facing the
#  street, shopfronts at ground level where the street is busy enough to want
#  them, and whatever the middle of the block turns out to be.
#
#  A district is authored rather than worked out from the road grid because a
#  block is a PLACE. It has a name, it can be clicked on, it can be told apart
#  from its neighbours, and when one of them is where somebody was last seen it
#  has to be something the map knows about rather than a gap between four roads.
# ==========================================================================

# ==========================================================================
#  THE COUNTRY
#
#  IT MOVED, because downtown grew into it. Home Farm, its yard, the big barn,
#  the paddocks, the fields and the shelter belt all stood between 360 and 720,
#  which is now the middle of the city. Every one of them is still here with its
#  name and its sentence intact; they are on the far side of the ring roads
#  instead, strung down the western strip where the map has room.
#
#  The strip is what is left between the north-south corridors: x 120..240 is a
#  hundred and twenty metres wide, runs the height of the map, and is broken into
#  cells by the east-west roads. A farm laid down a lane like that is not a
#  compromise - it is what a farm beside a road actually looks like.
#
#  Every lot is the pack's own measured footprint rounded up. House_Farm_British
#  is 13.8 x 15.1 and gets 15x16; Barn_Farm_Scandinavian is 17.1 x 37.9 and gets
#  18x39; Silo_Grain_Old is 6.7 x 6 and gets 7x7.
#
#  There is not an animal anywhere in this pack, so a paddock is fenced, gated
#  and troughed and stands empty. See the note in kinds.txt.
# ==========================================================================

#  160 x 100 tiles, one tile = one metre, exactly as Ashcombe.

#  This is NOT the city. It is one block, authored to answer whether the
#  existing content format carries a city at all and whether the bought models
#  sit on lots this file describes. Ashcombe stays untouched next door so the
#  two can be photographed under the same sun.
#
#  LOT SIZES COME FROM THE MODELS, not from taste. The townhouse module
#  measures 6.1m wide and 3.0m per floor, so a terrace lot is 6 wide and the
#  terrace is that repeated. Bayhouse is about 7m deep and Squarehouse 9m, so
#  lots are 8 and the renderer centres what it places. The landmarks are the
#  pack's own footprints rounded up: Diner_City is 19.6 x 10.5, and
#  Police_Station_City is 34.5 x 18.
#
#  That is the whole difference from Ashcombe, where the lot came first and
#  the geometry was generated to fill it. Here the model came first.
# ============================================================================

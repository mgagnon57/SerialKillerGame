# ============================================================================
#  NORTHGATE
#
#  360 x 360 tiles, one tile = one metre. The city fills the north-west quadrant
#  exactly as it did; the other three are country.
#
#      0                       240                 360
#  0   +--------------------------+-------------------+
#      |                          |                   |
#      |     T H E   C I T Y      |   the east fields |
#      |     nine 60m blocks      |   and the orchard |
#      |     four junctions       |                   |
#  240 +--------------------------+-------------------+
#      |  HOME FARM               |  the back place   |
#      |  and the cornfields      |  no made road     |
#  360 +--------------------------+-------------------+
#
#  THE ROAD KIT DECIDES THE GRID, not taste. Prefabs/City/Roads City is built at
#  thirty metres, so a through-road is a THIRTY-METRE CORRIDOR and the plan snaps
#  to thirty. What differs between an arterial and a main road is not the corridor
#  - both are thirty - but how much of it is asphalt:
#
#    freeway    30m corridor, 24m asphalt, two lanes each way, orange centre
#    mainroad   30m corridor, 12m asphalt, one lane each way
#    street     10m corridor,  6m asphalt, unmarked
#    track      10m corridor,  7m of dirt, no kerb and no markings
#
#  Because width alone cannot tell a freeway from a mainroad, the class is said
#  outright on an indented `class` line rather than inferred.
#
#  A ROAD IS TILED BETWEEN THE POINTS IT IS DECLARED BETWEEN. The four city roads
#  are declared edge to edge and so cross the whole map; a farm track is declared
#  from a map edge to the road it joins, and stops there. Declaring a track that
#  stops in a field would leave traffic driving off the end of it.
#
#  THE GROUND: grass everywhere, then the city paved over the top of it. Trees,
#  hedges and bushes are scattered by Prop.ScatterOn, which fires on grass, field,
#  wood and churchyard and on NOTHING else - so paving the city is what stops a
#  hedge growing down the middle of the avenue, and leaving the country unpaved is
#  what lets it grow anywhere at all.
#
#  Painted in order: terrain, then roads over terrain, then places over roads. An
#  open place STAMPS ITS GROUND, so a place laid over a road must have road for
#  its ground or it quietly erases the street - which is what the Elevated did to
#  Second Street in an earlier plan.
# ============================================================================

village Northgate
size 360 360

# ---- the ground ----------------------------------------------------------
terrain grass 0,0 360x360
terrain path  0,0 240x240

# ---- the street grid -----------------------------------------------------
# All four run the full width or height of the map, so every junction is a full
# crossing and the roads carry on out into the country rather than stopping at
# the edge of town.

road northgate 30 0,75 359,75
  class freeway

road franklin 30 0,165 359,165
  class mainroad

road first 30 75,0 75,359
  class mainroad

road second 30 165,0 165,359
  class freeway

# ---- the dirt tracks -----------------------------------------------------
# Each runs from a map edge to the made road it joins. Where a track meets a
# main road the junction piece is sized to the main road, which is right: a farm
# track does meet the highway at a proper metalled junction.

road hometrack 10 0,300 76,300
  class track

# Declared from inside Second Street's corridor, not from its edge: a junction
# only forms where one road's centre line falls INSIDE the other's declared run,
# and starting this at 166 left it one metre short of the centre at 165 - so the
# track met the street with no crossing between them.
road backtrack 10 150,318 359,318
  class track

# ============================================================================
#  NORTHGATE
#
#  1290 x 1290 tiles, one tile = one metre. A town in the middle of a country,
#  which is what the 960 map could not be: see the note on the rings below.
#
#      0        285                              1005      1290
#  0   +---------+----------------------------------+---------+
#      |                    the north country                  |
#  285 +---------+----------------------------------+---------+
#      |         |          S U B U R B S           |         |
#  375 |         |   +--------------------------+   |         |
#      |  west   |   |                          |   |  east   |
#      | country |   |    D O W N T O W N       |   | country |
#      |         |   |    six blocks square     |   |         |
#  915 |         |   +--------------------------+   |         |
#      |         |                                  |         |
# 1005 +---------+----------------------------------+---------+
#      |                    the south country                  |
# 1290 +---------+----------------------------------+---------+
#
#  THE GRID IS A NINETY-METRE PITCH and everything follows from it: a thirty-
#  metre corridor and a sixty-metre block, so roads land at 15 + 90k and N blocks
#  span 90N + 30. Fourteen blocks a side is 1290, which is why the map is that
#  number and not a round one.
#
#  THE MAP GREW BECAUSE THE COUNTRY HAD NOWHERE TO GO. On the 960 map the road
#  grid was not centred - the outer ring sat at 105 and 915, whose midpoint is
#  510 against a map centre of 480 - so outside it there was ninety metres on two
#  sides and THIRTY on the other two. Thirty metres is one corridor. There was no
#  version of that map with suburbs in it that still had a countryside, only a
#  version with the farm evicted for a second time. At fourteen blocks the frame
#  is 270m deep on every side and symmetric about the centre, which also puts
#  Second Street and Franklin Street dead through the middle at 645.
#
#  EVERYTHING THAT WAS ALREADY BUILT MOVED BY +120, by script, so every internal
#  relationship survived intact. Not half the growth: the town was centred on 525
#  in the old map, and 645 - 525 = 120. Taking it from the map size would have
#  pushed the whole city 45m off centre and quietly reintroduced the asymmetry
#  this re-lay exists to remove.
#
#  THE ROAD GRID STOPS AT THE SUBURB RING - nine roads each way, at 285 through
#  1005, and that is a traffic decision rather than a taste one. A full fifteen by
#  fifteen grid would be some two hundred junctions and would treble the lane
#  graph. The country gets the arterials running out through it and two farm
#  tracks, which is what country roads are.
#
#    freeway    30m corridor, 24m asphalt, two lanes each way, orange centre
#    mainroad   30m corridor, 12m asphalt, one lane each way
#    street     10m corridor,  6m asphalt, unmarked
#    track      10m corridor,  7m of dirt, no kerb and no markings
#
#  A ROAD IS TILED BETWEEN THE POINTS IT IS DECLARED BETWEEN. The arterials are
#  declared edge to edge; a farm track is declared from its farm to the road it
#  joins and stops there. A junction forms only where one road's centre line falls
#  INSIDE the other's declared run, which is why the tracks below overshoot the
#  road they meet by five metres.
#
#  Painted in order: terrain, then roads over terrain, then places over roads. An
#  open place STAMPS ITS GROUND, so a place laid over a road must have road for
#  its ground or it quietly erases the street.
# ============================================================================

# ==========================================================================
#  DOWNTOWN
#
#  THE TOWN IS THE INNER RING, not nine blocks in the middle of it. Northgate
#  used to be a 3x3 grid of sixty-metre blocks sitting alone inside five hundred
#  metres of arterial road, which reads as a village with a motorway network
#  bolted round it. The streets at 345, 615 and 705 close the grid up: with the
#  four that were already there, the square between the ring roads is now SIX
#  block-bands each way - thirty-six blocks of sixty metres, which is the scale
#  of a small city's walkable core rather than a hamlet's.
#
#  Nine of those blocks are the town as it was and are authored building by
#  building above. The other twenty-seven are `district`: an open place that
#  CityDistrict fills with a block - a perimeter of stacked buildings facing the
#  street, shopfronts at ground level where the street is busy enough to want
#  them, and whatever the middle of the block turns out to be.
#
#  A district is authored rather than worked out from the road grid because a
#  block is a PLACE. It has a name, it can be clicked on, it can be told apart
#  from its neighbours, and when one of them is where somebody was last seen it
#  has to be something the map knows about rather than a gap between four roads.
#
#  `units` IS HOW MANY LIVE IN THE BLOCK, and 29 is measured rather than liked:
#  CityDistrict reports 662 buildings across the twenty-three blocks it fills
#  with a perimeter, which is 28.8 apiece. It is not a home in its own right -
#  it has no rooms and nobody is housed in it one by one - so this feeds only
#  the things that scale to how busy the map is. See WorldModel.DeclaredHouseholds.
#  Before it existed the traffic budget counted households, a district had none,
#  and twenty-seven new blocks added not one car to the roads.
# ==========================================================================

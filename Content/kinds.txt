# ============================================================================
#  WHAT KINDS OF PLACE THERE ARE
#
#  One row per kind. Adding an amenity to the village is a row here and a few
#  lines in village.txt - it is not thirteen switch statements in eleven files,
#  which is what it used to be, and eleven chances to forget one.
#
#  A row is complete or the load fails. There is deliberately no default for
#  anything: a kind that forgets to say whether it has rooms was, before this
#  file existed, a building that quietly had none, and the first sign of it was
#  an empty box on the screen with nobody working in it.
#
#  A kind whose name matches a PlaceKind member keeps that member's number, so
#  the order of this file does not matter and cannot move anything. A kind the
#  enum has never heard of is numbered after them, and works everywhere in Core
#  without a line of C#. A barber, tried as one row here and four lines in
#  village.txt, came out walled, roofed, laid out inside, open Tuesday to
#  Saturday and with somebody behind the chair who had a trade of her own.
#  What such a kind does NOT get is anything the renderer still decides by
#  switch - its shopfront is the generic board - and nobody walks to it for a
#  haircut, because errands are still a weighted list in DayPlanner.
#
#  ---- the columns ------------------------------------------------------------
#
#  words      what village.txt may call it. The first is the canonical name.
#  form       building (walls, floor, a door) or open (bounded ground).
#  home       whether people LIVE here, and so whether households are made in it.
#             Optional, and unstated means "dwelling and nothing else", which is how
#             it behaved before the column existed. It exists because Core used to
#             ask for PlaceKind.Dwelling by its ENUM MEMBER, so a city of
#             `apartment` was built with forty homes and nobody in one of them -
#             the open-kind promise held everywhere except the one place it mattered.
#  ground     what open ground is made of. Only for `form open`.
#  rooms      none, or auto - however many the grammar thinks a building of
#             this sort needs. A stated range is refused until a grammar takes
#             one, rather than accepted and then ignored.
#  grammar    which interior grammar lays it out, by name. Only when it has
#             rooms, and it must be a name InteriorGenerator answers to.
#  roof       whether it has a roof, and therefore whether its windows light.
#  frontage   which shopfront the renderer hangs on it.
#  props      outdoor furniture belonging to the place: benches, postbox, trough.
#  counter    whether you are served one at a time, and therefore queue.
#  service    minutes at the counter: this many, plus a draw under the spread.
#             Only where there is a counter.
#  hours      when it is open, WHEN THE PLACE DOES NOT SAY FOR ITSELF. Every
#             place in Ashcombe states its own, so these are what a second shop
#             or a new surgery would open for if nobody wrote it down.
#  jobs       how many work there, again only when the place does not say.
#  roles      what those people are called, in slot order. The last name covers
#             every slot after it: "farmer farmhand" is one farmer and the rest
#             hands. A kind that names roles must employ somebody, and a kind
#             that employs somebody must name what they are - either on its own
#             is an amenity whose windows never light from anyone being in it.
#  shifts     one, or split when several opening windows are genuinely separate
#             shifts rather than a lunch break. Only the mill.
#  catchment  whether a household belongs to a particular one of these.
#  describe   whether it is expected to carry its own `human` sentence. A
#             dwelling is not: its character comes from who lives in it.
# ============================================================================

# ============================================================================
#  CITY KINDS
#
#  Added for the city built from bought models (see
#  docs/superpowers/specs/2026-07-29-poly-universal-pack-integration-design.md).
#  None of these exists in the PlaceKind enum, which is the point: the table is
#  open, so they are numbered after the enum members and work everywhere in
#  Core without a line of C#. What they do NOT get for free is geometry - the
#  renderer decides that, and for these it places bought prefabs rather than
#  generating walls.
#
#  `massing` still names a village grammar because the massing grammars are
#  what the OLD renderer reads; an unknown name falls back to cottage with a
#  warning. Once CityBuildings owns these kinds the column stops being read
#  for them.
# ============================================================================

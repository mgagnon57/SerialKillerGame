# ============================================================================
#  ASHCOMBE
#
#  170 x 120 tiles, one tile = one metre.
#
#  Houses are sized so people can actually live in them. A 6x7 cottage is 6m by
#  7m, which after one-metre walls leaves 20 m2 of floor - too small for a
#  bedroom AND a bathroom, so families of four were living in two rooms. These
#  are 8x8 to 12x10: a real 1970s village house, 50-90 m2, three or four rooms.
#
#  Interiors are generated per building (see InteriorGenerator) so no two
#  layouts are identical. Only the footprint and the front door are authored.
#
#  Painted in order: terrain, then roads over terrain, then buildings over
#  roads. Read top to bottom and you know what covers what.
#
#  The `human` line is the ONLY text the UI may ever show about a place.
# ============================================================================

# ============================================================================
#  THE NEW BUILDING, 1972-4
#
#  Ashcombe grew east when the mill took on a second shift. The old parish
#  stops at Mill Lane; everything past it went up in three years and looks it -
#  straight lanes, repeated terraces, no building older than the people in it.
#
#  This is also where the map had to get bigger. The old 170x120 was FULL. Four
#  terraces were tried inside it first and the layout checker refused every one:
#  the only gaps left were the green, the playground and the allotments, and a
#  village that concretes its own open ground to house people has not grown, it
#  has got worse. So the map went 170 -> 210 wide and the new quarter went on
#  clean ground east of Mill Lane.
# ============================================================================

# ============================================================================
#  WHAT THE COUNTY SAYS ABOUT EACH PARCEL - VERMILION COUNTY, ILLINOIS
#
#  776 of Rossville's 794 surveyed parcels, matched against the Supervisor of
#  Assessment's own property service (the same
#  gis.cityofdanville.org/arcgis/rest/services/Property/Property that supplied
#  the parcel geometry) by nearest-centroid Hungarian assignment: median 4.4m,
#  90th percentile 6.5m, worst 45.9m. Raw records at
#  tools/rossville-property-records.json so this can be rebuilt.
#
#  ONLY WHAT THE COUNTY LITERALLY RECORDS. Nothing here is inferred, averaged
#  or invented - zoning, house size and household shape are all DERIVED FROM
#  these numbers in code (see CountyRecord.cs), never baked in here, so the
#  derivation can be corrected without the source data being touched.
#
#  OWNER NAMES: RULE CHANGED BY THE OWNER, 2026-08-04.
#
#  This file used to say NO OWNER NAMES, DELIBERATELY, on the grounds that real
#  names at real addresses would make identifiable living people into the
#  victims of a murder simulation. The owner has reversed that, in his words:
#  "this will never ship with any real names ... this is just for researching
#  who lived where ... note to not ship it out to sources with real names, but
#  I need them for design."
#
#  So the rule is now about WHERE A NAME MAY GO, not whether one may be looked
#  up. Three things hold, and they are the whole of it:
#
#    1. NOTHING SHIPS WITH A REAL NAME. Households in the built game are
#       generated from Content/names.txt, which is tuned for Rossville in 1991
#       - Kentucky/Ohio/Indiana stock with an Irish railroad minority. A real
#       name may inform which household goes where; it may not BE the household.
#
#    2. NO REAL NAME LEAVES THIS MACHINE. Not into a web search, not into an
#       API call, not into a bug report, not into a commit message. Research a
#       name locally and it stays local. This is the "no shipping it out to
#       sources" the owner asked to have written down.
#
#    3. THE ANALYSIS THAT WORRIED US STILL WORRIES US. TXOV65 and TXOWOC flag
#       which owners are over 65 and which live alone. Joining those to real
#       names produces a list of isolated elderly people at real addresses.
#       That join is not design research and there is no version of this game
#       that needs it.
#
#  The name field is still not in this file, because the source download does
#  not contain one - see the FIELDS list below. Adding names is a separate,
#  deliberate act against a separate source, not something to slip in here.
#
#  FIELDS
#    pin        the county's parcel identification number
#    address    situs address, county spelling, title-cased. 577 have one; the
#               rest are vacant land, farm ground or right-of-way the county
#               has never had reason to address, and blank is the ANSWER there
#               rather than a gap.
#    class      the county's own property class code and its own wording
#    occupancy  owner | absentee | other. `owner` is the county's own
#               owner-occupancy flag (TXOWOC). `absentee` means the owner's
#               tax bill goes somewhere other than the property itself, which
#               is what a rented house looks like in the record. The mailing
#               address ITSELF is never stored - only this flag derived from
#               whether it differed.
#    over65     present only when the county's over-65 exemption is claimed;
#               a fact about the OWNER, used only as a rate when generating
#               household ages, never to identify anybody
#    assessed   homesite and dwelling assessed value, in dollars. Illinois
#               assesses at one third of market value, so dwelling x3 is
#               roughly what the structure is worth - the best proxy the
#               public record gives for how big and how good a house is,
#               because this county publishes NO square footage, bedroom or
#               bathroom data anywhere online. Checked: the tax card carries
#               billing and assessment only.
#    acres      the county's own acreage for the lot
#
#  Keyed by the parcel's line number in parcels.txt (0-based, comments and
#  blanks not counted), matching Content/parcel-notes.txt.
#
#  Fetched and matched 2026-08-01. Earliest tax year the county publishes
#  online is 2007; 1991 rolls exist only on paper at the courthouse.
# ============================================================================
